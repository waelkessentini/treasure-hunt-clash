# Treasure Hunt Clash

A tabletop card game for up to four treasure hunters, played in the browser. Each round everyone secretly picks Dig, Steal, Guard or Double Dig, then all the cards flip at once. The first to 10 gold wins. Empty seats are played by AI rivals.

**Play:** https://waelkessentini.github.io/treasure-hunt-clash/

## Playing with friends
1. Open the link, type your name and press **Host a table**.
2. Send your friends the 5-letter code, or press **Copy invite link**.
3. Friends open the link, type a name and press **Join**.
4. Press **Deal the cards**.

The host's browser runs the table, so keep that tab open. Browsers connect directly to each other; the free public PeerJS server only introduces them. Some strict networks (offices, schools, some mobile carriers) block direct connections.

The whole game is the single file `index.html`.
